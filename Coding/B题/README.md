## 二、快速开始

### 1. 离线开发（推荐，不消耗任何测试机会）

```bash
# 终端 A：启动离线模拟器
python offline_sim.py --port 2027 --jammers 14 --seed 42

# 终端 B：运行可用性测试（验证通信链路）
B_SIM_URL=http://127.0.0.1:2027 python usability_test.py --no-wait
```

离线模拟器额外参数：
- `--jammers N` 干扰源个数（官方为 10–16）
- `--directional-ratio 0.4` 定向源比例（问题 3 用 0，问题 4 用 0.3–0.5）
- `--seed S` 固定随机种子，保证实验可复现

本地真值接口（**官方模拟器没有**，仅开发用）：
```bash
curl http://127.0.0.1:2027/debug/truth     # 看干扰源真实位置/总数/已清除数
```

## 四、API 速查（详见 `.claude/skills/b-simulator/references/api_reference.md`）

只有 4 条指令，全部 `POST` + JSON：

| 指令 | 作用 | 虚拟耗时 |
| --- | --- | --- |
| `/enter` | 进入，开始计时 | 0 |
| `/measure` | 移动 + 切频道 + 检测 | 移动 + 切换(0/1s) + **5s** |
| `/clear` | 移动 + 精确定位 + 清除 | 移动 + (**3s** 未发现 / **5s** 成功) |
| `/exit` | 结束 | 0 |

返回码：

- `/measure` → `measure_result`：`no_signal` / `near` / `direction`（带 `svd_deg`）
- `/clear` → `clear_result`：`success` / `no_target_in_range`

**物理常数**：速度 5 m/s ｜ 近距离阈值 5 m ｜ 清除半径 20 m ｜ 示向度误差 ±1°
｜ 有效接收半径 1000–1500 m（不返回）｜ 区域半径 1800 m ｜ 频道 1–20

## 五、六个必踩的坑（客户端已处理，自己写代码时注意）

1. **`accepted=false` 时 `virtual_time_s` 恒为 0**，不是当前时刻 → 用最近一次 `accepted=true` 的值
2. **必须同时检查 HTTP 状态码和 `accepted`**
3. **新动作必须新 `request_id`**；仅网络重试同一动作才复用原 ID + 原内容，否则 409
4. **严格串行，禁止并发**
5. **接口未开放时连接直接失败（无 JSON body）**，要同时处理"连不上"和"收到 JSON"
6. **`/clear` 的 channel 是目标源频道，不切频道、不产生切换耗时**
