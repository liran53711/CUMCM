## §1 结论陈述

> **命题 A** 设 $\mathcal{P}\subset\mathbb{R}^2$ 为非空紧集，$c$ 为其最小包围圆的圆心、$r_{\text{MEC}}$ 为其半径，$\mathcal{D}=\operatorname{diam}(\mathcal{P})$。则
> $$r_{\text{MEC}}\ \ge\ \frac{\mathcal{D}}{2}.$$

> **推论** 若 $\dfrac{\mathcal{D}}{2}>r_{\text{clear}}$，则**不存在**任何位置 $q$，使得到 $\mathcal{P}$ 中任意点的距离都不超过 $r_{\text{clear}}$。

**推论的大白话**：只要定位区域的**直径大于清除半径的两倍**，就没有任何一个点能让你站上去清掉整个区域——**必须走近**。

## §2 证明

### 2.1 命题 A

由最小包围圆的定义，$\mathcal{P}$ 中任意点都落在以 $c$ 为心、$r_{\text{MEC}}$ 为半径的闭圆盘内：

$$\forall p\in\mathcal{P}:\quad \lVert p-c\rVert\le r_{\text{MEC}}. \tag{1}$$

因 $\mathcal{P}$ 非空紧、$\lVert\cdot\rVert$ 连续，直径在 $\mathcal{P}$ 中取到，故存在 $A,B\in\mathcal{P}$ 使 $\lVert A-B\rVert=\mathcal{D}$。对 $A,B$ 应用**三角不等式**：

$$\mathcal{D}=\lVert A-B\rVert=\bigl\lVert(A-c)+(c-B)\bigr\rVert\le\lVert A-c\rVert+\lVert c-B\rVert\overset{(1)}{\le}r_{\text{MEC}}+r_{\text{MEC}}=2r_{\text{MEC}}.$$

两边同除以 $2$，得 $r_{\text{MEC}}\ge\dfrac{\mathcal{D}}{2}$。$\blacksquare$

### 2.2 推论

反设存在这样的 $q$，即 $\mathcal{P}\subseteq\mathrm{D}(q,r_{\text{clear}})$。则 $\mathrm{D}(q,r_{\text{clear}})$ 是 $\mathcal{P}$ 的一个包围圆，故其半径不小于最小包围圆半径：

$$r_{\text{MEC}}\le r_{\text{clear}}. \tag{2}$$

但由命题 A，

$$r_{\text{MEC}}\ge\frac{\mathcal{D}}{2}>r_{\text{clear}}. \tag{3}$$

(2) 与 (3) 矛盾。故这样的 $q$ 不存在。$\blacksquare$

### 2.3 证明用到的全部依据

| 依据 | 用在哪一步 |
| --- | --- |
| 最小包围圆的定义（$\mathcal{P}$ 全落在圆盘内） | 式 (1) |
| $\mathcal{P}$ 非空紧 + 范数连续 $\Rightarrow$ 直径取到 | 存在 $A,B$ |
| 三角不等式 $\lVert x+y\rVert\le\lVert x\rVert+\lVert y\rVert$ | 命题 A 唯一的关键一步 |
| 最小包围圆的最小性 | 式 (2) |
| 反证法 | 推论 |

**全篇只用了一条不等式**——三角不等式。这就是它可靠的原因。

## §3 为什么说它是「额外的」

Q1 原文只问两件事：

| Q1 问的 | 本文档回答的 |
| --- | --- |
| ① 给出计算定位区域直径的算法 | ✗ 与之无关 |
| ② 以定位区域直径为直径的圆能否覆盖此定位区域 | ✗ 与之无关 |

**命题 A 和推论不在题目要求之内。** 但它是这样掉出来的：

```
题目问：直径圆能不能盖住定位区域？
        → 要回答它，必须引入"最小包围圆"作参照（等价命题）
        → 既然引入了 r_MEC，顺手就能拿到它和 D 的不等式
        → 拿到不等式，再和 r_clear=20 一比，Q3 的流程就被锁死了
```

所以它是**求解过程中的自然副产品**，而不是额外的工作量。

### 3.1 它比「覆盖 $=$ 是」更有用

| | 「直径圆覆盖 $=$ 是」 | 「$r_{\text{MEC}}\ge\mathcal{D}/2=87.9>20$」 |
| --- | --- | --- |
| 回答了什么 | Q1 的字面提问 | Q1 **没问**但真正决定后续的问题 |
| 依赖区域具体形状？ | 是（取决于 $\varepsilon$、检测点几何） | **否** |
| 依赖「覆盖」的判定结果？ | — | **否**，只用下界 $\mathcal{D}/2$ |
| 数据一变还成立？ | 可能翻转 | 只要 $\mathcal{D}>40$ m 就成立 |
| 对 Q3 的作用 | 无 | **证明「先逼近、后清除」是唯一可行流程** |

> **注意第 3 行。** 这是它分量最重的地方：推论**不依赖覆盖判定的结果**。
> 即使覆盖判定翻转为「否」，甚至即使定位区域形状完全变了，
> 只要 $\mathcal{D}>2r_{\text{clear}}=40$ m，结论就照样成立。
> 因此它在论文里可以**无条件地写**，不需要任何"在该算例下"的限定语。

## §4 代入本题

本题所用数据（来源见文末 ⚠）：

| 量 | 值 |
| --- | --- |
| $\mathcal{D}$ | $175.8$ m |
| $\mathcal{D}/2$ | $87.9$ m |
| $r_{\text{MEC}}$ | $87.9$ m |
| $r_{\text{clear}}$ | $20$ m |

$$\frac{\mathcal{D}}{2}=87.9\ \text{m}\ >\ 20\ \text{m}=r_{\text{clear}}$$

$$\Longrightarrow\ \boxed{\ \text{不存在任何单点，能同时覆盖整个定位区域并落在清除距离内}\ }$$

**余量**：$87.9/20=4.4$。即令 $\mathcal{D}$ 缩小到原来的 $1/4$ 多一点，不等式仍然成立——
这条结论**不是靠边际数据撑起来的**。

## §5 对问题 3、问题 4 的意义

| 问题 | 这条结论锁死了什么 |
| --- | --- |
| **问题 3** | 「先逼近、后清除」不再是"一种可选策略"，而是**几何上唯一可行的流程**。报告里可以直接写：因 $\mathcal{D}/2\gg r_{\text{clear}}$，任何"测到即清除"的方案在数学上不可能成立 |
| **问题 3（在线判据）** | 逼近到什么时候停？判据即为 $\mathcal{D}\le 2r_{\text{clear}}=40$ m；等价地 $r_{\text{MEC}}\le20$ m。这把"停下"的时刻变成一个可计算的量 |
| **问题 4** | 定向源在盲区返回 `no_signal`，需多方向复测——但那属于**示向度获取**的问题；本文结论只依赖 $\mathcal{D}$，故**照常成立**，不受盲区影响 |

> **一句话**：Q1 输出的不是一个"是/否"，而是一条**关于精度的下界**。
> 这条下界告诉你：无论算法多聪明，只要还在远场，就清不了。

## §7 常见扣分点

| # | 毛病 | 正确做法 |
| --- | --- | --- |
| 1 | 直接写「因为区域太大所以清不了」 | 直觉可写在问题分析里，但结论处必须给三角不等式 |
| 2 | 用 $\mathcal{D}/2$ 时不说它是什么半径 | 先声明 $\mathcal{D}/2$ 是直径圆半径，$r_{\text{MEC}}$ 是最小包围圆半径，二者不等 |
| 3 | 忘记说直径能取到 | 加一句「$\mathcal{P}$ 非空紧、范数连续，故最大值取到」 |
| 4 | 把推论写成「一般不能」 | 是**绝对不可能**（反证得出的矛盾），不是概率或经验判断 |
| 5 | 结论里写「在本算例下」 | 命题 A 与推论**无条件成立**，不必也不应加此类限定语 |
