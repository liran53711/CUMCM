## 问题 1：怎么建模 $n$ 个 2° 楔形的交

### 最直观的做法：不要「构造」，先写「判定」

不要一上来就想「这个多边形长什么样」。最直观的是**反过来**——先能判断「一个点在不在里面」。

第 $i$ 个楔形给出两个条件，用叉积写：

$$u_i \times (p-S_i) \ \ge\ 0 \qquad\text{且}\qquad v_i \times (p-S_i) \ \le\ 0$$

其中

$$u_i=\bigl(\cos(\theta_i-\varepsilon),\ \sin(\theta_i-\varepsilon)\bigr),\qquad v_i=\bigl(\cos(\theta_i+\varepsilon),\ \sin(\theta_i+\varepsilon)\bigr)$$

$a\times b = a_xb_y-a_yb_x = |a||b|\sin(\angle b-\angle a)$，$\varepsilon=1°$。

**一句话解释**：$a\times b>0$ 表示「从 $a$ 逆时针转到 $b$」的角度在 $(0°,180°)$ 内。
于是 $u_i\times(p-S_i)\ge0$ 说的就是：**从楔形的下边界出发、逆时针转到「$S_i$ 指向 $p$」的方向**，转过的角不超过 $180°$——即 $p$ 的方位 $\ge\theta_i-\varepsilon$。
同理 $v_i\times(p-S_i)\le0$ 给出 $p$ 的方位 $\le\theta_i+\varepsilon$。
两式合起来，正是**方位落在 $[\theta_i-\varepsilon,\ \theta_i+\varepsilon]$ 内**。

> ⚠ **叉积次序不可颠倒**。写成 $(p-S_i)\times u_i$ 符号完全相反，接受的角度区间变成 $[179°,181°]$——
> 楔形**转向了 $180°$ 的反方向**。仍然是个 $2°$ 细条，所以不报错、看着合理，但源被定到检测点另一侧。详见 `问题1-详解与思路评估.md` §1.3。

那么：

$$p\in\text{定位区域} \iff \text{对全部 } n \text{ 个 } i \text{ 都成立}$$

**判断「在不在区域内」就这么简单——$n$ 个不等式而已。**

### 要拿到多边形（顶点），最直观是「穷举 + 筛」

**关键观察**：区域的边一定落在某条射线上，所以**顶点一定是两条射线的交点**。

于是算法为：

```
所有 2n 条射线两两求交              → 得到一堆候选点
对每个候选点 p：
    若 p 在所有 n 个楔形内          → p 是顶点，保留
    否则                           → 丢弃
保留下来的点就是定位区域的全部顶点
```

**这就是最直观的方法：穷举所有交点，再用判定函数筛。**

复杂度：$C(2n,2)\approx 2n^2$ 个交点，每个查 $n$ 次 → $O(n^3)$。$n\le10$ 时不到 8000 次运算，可忽略。

### 这类多边形的共同特征

| # | 特征 | 原因 |
| --- | --- | --- |
| 1 | **一定是凸集**（边界约定下为凸多边形） | 每个楔形是凸集，凸集之交仍为凸集 |
| 2 | 顶点数 $\le 2n$ | 最多 $2n$ 条边各贡献一个顶点 |
| 3 | 每个顶点是**两条来自不同检测点**的射线交点 | 同一点的两条射线交于该点自身，非一般位置 |
| 4 | 通常是个**细长条** | 张角只有 $2°$ |

### 这些特征有用吗？——**特征 1 是全部的关键**

> **凸性一确立，问题 2 和问题 3 立刻从「连续优化」退化为「有限枚举」。**

这是本题最值钱的一步，后两问全靠它。

- 特征 3 也有用：把「平面上无穷多个点」缩成「有限个候选」。
- 特征 4 有解释价值：细长 $\Rightarrow$ 直径由两端尖角决定，交会角越小越细长。

## 问题 2：怎么找多边形内最远的两点

### 最直观：所有顶点两两配对，取最大距离

$$\mathcal{D}\;=\;\max_{1\le j<k\le m}\ \lVert p_j-p_k\rVert$$

两层循环，$O(m^2)$，$m\le 2n$。

### 为什么「只查顶点」就够？——直觉说法

> **最远的那对点，一定是「角顶角」。**

因为对凸多边形来说，**顶点是最「鼓」出去的地方**。任何边的中间点都夹在两个端点之间；任何内部点都被角围住。所以找最远的，一定往角上找。

**这就是凸性为什么重要**：若是凹多边形，最远点可能藏在凹口的边上，只查顶点就漏了。

> **严格证明**（论文中需写出）：固定 $b$，函数 $a\mapsto\lVert a-b\rVert$ 是**凸函数**；
> 凸函数在紧凸集上的最大值必在极点（顶点）取得。再对 $b$ 同理。
> 两个「同理」合起来 $\Rightarrow$ 直径必在顶点对之间取到。$\blacksquare$

### 更聪明的做法（现在不用）

**旋转卡壳（rotating calipers）**：$O(m)$。

但 $m\le2n\le20$，$O(m^2)=400$ 次运算，**没必要优化**。
论文里可提一句「可用旋转卡壳优化到 $O(m)$」，作为「知道更优算法但此处不需要」的加分点。

## 问题 3：怎么判断有没有点跑到圆外

### 先看清题目在问什么

设最远两点为 $A,B$，则

$$\mathcal{D}=\lVert A-B\rVert,\qquad M=\frac{A+B}{2},\qquad R=\frac{\mathcal{D}}{2}$$

**关键观察：$A$ 和 $B$ 本来就在圆上**（到 $M$ 的距离恰好为 $R$）。

所以问题变成：

> **除了 $A,B$ 之外，还有没有别的顶点跑到圆外去了？**

### 最直观：直接算距离

```
对每个顶点 p：
    计算 |p - M|
    若 > R  → 有顶点跑出圆外，判定「盖不住」
全部 ≤ R    → 判定「覆盖」
```

### 为什么「只查顶点」就够？——直觉说法

> **圆是凸的，多边形也是凸的。角都在圆里，边和内部自然也在圆里。**

反过来：**只要有一个角在外面，就说明盖不住**——因为那个角实打实属于多边形。

**注意这个推理与问题 2 不同**：

| | 用的凸性在论证什么 |
| --- | --- |
| 问题 2 | 「最大值一定在顶点处取得」 |
| 问题 3 | 「只需检查顶点就足够」 |

两者**都依赖特征 1（凸性）**。这正是「凸性是关键」的含义。

### 更省事的等价判法：泰勒斯定理

不用开根号、不用算圆心，只算**点积的符号**：

$$p \text{ 在圆内} \iff \angle A p B \ \ge\ 90° \iff (A-p)\cdot(B-p)\ \le\ 0$$

> **泰勒斯定理**：$A,B$ 为直径两端时，圆周上任一点 $P$ 满足 $\angle APB=90°$；
> 圆内为钝角，圆外为锐角。
>
> **纯符号运算，数值上比「算距离再比大小」更稳健，也更快。**

## 直觉在这里够用吗？——三处必须补

以上三个「最直观」版本在数学上都成立，但要在论文中站住，有三处必须补：

| # | 直觉版本的漏洞 | 补法 |
| --- | --- | --- |
| 1 | **「穷举射线交点」没处理无界情形**。两射线近似平行时交点跑到无穷远；所有楔形之交为空时没有顶点 | 加外部边界（目标区域圆 / $r_{\text{eff}}$ 圆盘），并显式讨论退化 |
| 2 | **「顶点数 $\le2n$」只给了上界**，未说实际几个。可能只有 3 个（三角形）甚至 2 个（细长条） | 给出顶点数的判定方法，或接受「算法自动得出」 |
| 3 | **「筛」依赖射线是直线还是半直线**。严格说楔形边界是**半直线**，交点参数必须 $>0$ | 求交时只取 $t>0$ 的解 |

> 第 3 点就是 `geometry.py` 中 `ray_intersection` 只接受 $t>0$ 的原因——
> **这不是实现细节，是数学上必须的。**
