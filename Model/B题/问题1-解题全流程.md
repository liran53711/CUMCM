## §0 先回答：需要模拟吗？

**分问题看，答案不同。**

| 问题 | 需要模拟器吗 | 依据 |
| --- | --- | --- |
| **问题 1** | ❌ **完全不需要** | 题面：「**已知**若干个检测点坐标及某干扰源关于这些检测点的示向度，请给出……的**算法**」 |
| **问题 2** | ❌ **不需要** | 题面：「已知某全向干扰源在一个检测点处测得的示向度，请给出第二个检测点的**选择策略**」 |
| **问题 3** | ✅ **必须** | 题面：「请通过模拟器进行演练测试」＋「导出三次正式测试的日志文件，放入支撑材料」 |
| **问题 4** | ✅ **必须** | 题面：「并通过模拟器进行演练测试（见附录 4）」，同样要交日志 |

**为什么问题 1、2 不需要模拟？**

因为这两问的措辞是「**已知**……请给出**算法/策略**」。它们在问**方法论**，不是在问**一次具体实验的结果**。

- 问题 1 的交付物 = **一个算法 + 一个覆盖判定准则**
- 问题 2 的交付物 = **一个选点策略 + 候选区域**

**数据是给定的前提，不是你要去采集的东西。**

**为什么问题 3、4 必须模拟？**

因为这两问的措辞是「请**制定策略并设计算法**，请**通过模拟器进行演练测试**」，还硬性要求导出三次正式测试日志放进支撑材料。**这是必须在模拟器里真跑的任务**，且正式测试只有 3 次机会。

## §1 一个必须澄清的误解：模拟器不给检测点坐标

这一点很关键，**想错了会导致整个问题 3 的策略设计跑偏**：

> 附录 3 原文：「测试中每个案例包括以下数据：目标区域中干扰源的个数、频道编号、位置、有效接收半径等，**所有数据无法直接读取**。」

**模拟器什么都不直接给你。** 那「检测点坐标」从哪来？

> **检测点坐标 = 你程序里机器狗自己站的位置。**

机器狗在 $(x,y)$ 时你调 `/measure`，这个 $(x,y)$ 是**你自己的程序变量**；模拟器只回一个示向度。所以：

| 量 | 谁提供 | 说明 |
| --- | --- | --- |
| 检测点坐标 $S_i$ | **你自己的程序** | 机器狗走到哪就是哪 |
| 示向度 $\theta_i$ | **模拟器**（`/measure` 返回） | 带 $\pm1°$ 误差 |
| 干扰源真实位置 | **谁都不给** | 只能靠算法推算 |
| 有效接收半径 $r_{\text{eff}}$ | **谁都不给** | 只知道在 $[1000,1500]$ 内 |

**所以：**

- 问题 1 的「已知检测点坐标」是**题设给的抽象前提**——在问题 3、4 里它天然成立，因为坐标就是你自己的位置
- 问题 1 真正要设计的，是**从「坐标 + 示向度」到「定位区域直径 + 覆盖判定」的算法**

### 那我们还是需要一份"实测数据"吗？

**需要，但用途是「验证」而不是「输入」。**

- **验证用**：拿真实数据跑一遍，证明算法能work、数值对得上
- **我们已经有现成的**：2026-09-10 那次演练拿到同一频道 2 的两条示向度
  $S_1=(300,400),\ \theta_1=214.82°$ 与 $S_2=(300,0),\ \theta_2=192.75°$
  → 算出直径 $175.8$ m，已写进 `Coding/B题/geometry.py` 的回归测试（11/11 通过）
- **这组数据直接就是论文「实例验证」小节的素材**

> **结论**：问题 1 的**算法设计**不需要模拟器；但**实例验证**需要一份真实数据，而这份数据我们已经有了。

## §2 全流程总览

```
┌─ 输入 ────────────────────────────────────────────────────────┐
│  n 个检测点坐标 S₁…Sₙ                                          │
│  n 个示向度     θ₁…θₙ                                          │
│  误差界         ε = 1°                                          │
└───────────────────────────────────────────────────────────────┘
                              │
   步骤 0  定外部边界 B        │  ← 建模假设，必须显式声明
                              ▼
   步骤 1  楔形 → 半平面        │  ← 把角度约束线性化
                              ▼
   步骤 2  求交 → 顶点集        │  ← 穷举 + 筛
                              ▼
   步骤 3  顶点按极角排序       │  ← 得到多边形顶点序
                              ▼
   步骤 4  直径 D 与端点 A,B    │  ← 顶点两两距离取最大
                              ▼
   步骤 5  覆盖判定             │  ← 泰勒斯点积，纯符号
                              ▼
   步骤 6  最小包围圆 r_MEC     │  ← 通向问题 3 的桥
                              ▼
   步骤 7  验证 + 灵敏度        │  ← 实测回归 / 蒙特卡洛
                              │
┌─ 输出 ────────────────────────────────────────────────────────┐
│  直径 D（精确值）                                              │
│  覆盖与否（确定答案）＋ 若否，指出哪个顶点跑出去了              │
│  最小包围圆半径 r_MEC 及其与清除半径 20 m 的关系               │
└───────────────────────────────────────────────────────────────┘
```

**一句话概括**：**把 $n$ 个角度约束变成 $2n$ 个线性约束，求交得到一个凸集（§0.5 边界约定下为凸多边形），然后在极点（即顶点）上做两次枚举。**

## §3 逐步展开

### 步骤 0 — 定外部边界 $\Omega$

| 项 | 内容 |
| --- | --- |
| **输入** | 题目给出的区域与设备参数 |
| **做法** | 取两条**已知信息**的交 |
| **输出** | 有界凸集 $\Omega$ |

**两条信息分别是：**

1. **源在目标区域内**（题面）⟹ 在以原点为心、$1800$ m 为半径的圆盘内
2. **检测点能测到它**（附录 2(2)）⟹ 在以**该检测点**为心、$r_{\text{eff}}\le1500$ m 为半径的圆盘内

第二条对**每一个成功测量的检测点都成立**，所以可以叠 $n$ 次：

$$\Omega=\underbrace{\text{disk}\bigl(O,\ 1800\bigr)}_{\text{源在目标区域内}}\ \cap\ \underbrace{\bigcap_{i=1}^{n}\text{disk}\bigl(S_i,\ 1500\bigr)}_{\text{每个检测点都收到了它}}$$

> 💡 **这是一个免费的收紧**：每测到一次，就多一个"源在以我为心 1500 m 内"的约束。
> 检测点分得越开，这组约束收得越紧。

**$r_{\text{eff}}$ 未知怎么办？** 取 $1500$（最大值）。
理由：$r_{\text{eff}}$ 越大 ⟹ 圆盘越大 ⟹ 约束越松 ⟹ 得到的区域**一定包含**真实区域。这是**保守的、安全的**。
然后在灵敏度分析里讨论 $r_{\text{eff}}\in\{1000,1250,1500\}$ 时直径怎么变。

> **「取值不定就取保守侧」是通用建模手法，问题 2 直接复用。**

**能干什么**：把无限延伸的楔形家族**有界化**。没有这一步，步骤 4、5 根本无解（直径可能是 $\infty$）。

### 步骤 1 — 楔形 ⟶ 半平面

| 项 | 内容 |
| --- | --- |
| **输入** | $S_i,\ \theta_i,\ \varepsilon$ |
| **公式** | $u_i\times(p-S_i)\ \ge\ 0$ 且 $v_i\times(p-S_i)\ \le\ 0$ |
| **输出** | $2n$ 个半平面 |

其中 $u_i=\bigl(\cos(\theta_i-\varepsilon),\sin(\theta_i-\varepsilon)\bigr)$，$v_i=\bigl(\cos(\theta_i+\varepsilon),\sin(\theta_i+\varepsilon)\bigr)$，$a\times b=a_xb_y-a_yb_x=|a||b|\sin(\angle b-\angle a)$。

**能干什么**：

1. **把"角度落在 $\pm1°$ 内"这个非线性约束，变成两个线性不等式** → 后续全部化为标准计算几何
2. **天然不怕 $0°$ 绕圈** —— 用 atan2 比大小的话，$359°$ 和 $1°$ 跨零要特判，叉积不用
3. 纯乘减法，数值稳健

> ⚠ **叉积次序不可颠倒**（写成 $(p-S_i)\times u_i$ 会把楔形转到 $180°$ 反方向，且**不报错**）。
> 已数值验证并修正，见 `问题1-详解与思路评估.md` §1.3。

---

### 步骤 2 — 求交得到定位区域顶点集

| 项 | 内容 |
| --- | --- |
| **输入** | $2n$ 个半平面 + $\Omega$ |
| **做法** | 穷举射线交点 → 用判定函数筛 |
| **输出** | 顶点集（$m\le2n$ 个，再加 $\Omega$ 贡献的） |

**关键观察**：区域的边一定落在某几条楔形边界上 ⟹ **每个顶点必是两条射线之交**。

```
候选点生成：所有 2n 根射线两两求交（只取参数 t > 0 的解）
    ↓
筛：对每个候选点 p，查是否满足全部 n 个楔形的判定
    ↓
 全过 → 留下（是顶点）
 有不过 → 丢掉
    ↓
再加入 B 的边界与各射线的交点
```

**复杂度**：$C(2n,2)\approx 2n^2$ 个候选 × 每个查 $n$ 次 = $O(n^3)$。$n\le16$ 时不到 8000 次乘法。

**能干什么**：**把"无穷多个点"变成"有限个顶点"** —— 这是后面两步能成立的前提。

> ⚠ **必须只取 $t>0$ 的解**。楔形边界是**半直线**不是直线，负方向的交点几何上无效。

---

### 步骤 3 — 顶点按极角排序

| 项 | 内容 |
| --- | --- |
| **做法** | 以区域形心为基准，按极角排序 |
| **输出** | 多边形顶点序 $p_1,p_2,\dots,p_m$ |

**能干什么**：得到**有序**顶点表。画图、算面积、判凸性都需要顺序。
（步骤 4、5 本身不依赖顺序，但论文配图和后续多边形运算需要。）

---

### 步骤 4 — 计算直径 $\mathcal{D}$

| 项 | 内容 |
| --- | --- |
| **输入** | 顶点集 |
| **定理** | **凸性 ⟹ 直径必在两个顶点之间取得** |
| **公式** | $\mathcal{D}=\max_{1\le j<k\le m}\lVert p_j-p_k\rVert_2$ |
| **输出** | $\mathcal{D}$ 及其两端点 $A,B$ |

**为什么只查顶点就够？** 固定 $b$，函数 $a\mapsto\lVert a-b\rVert$ 是凸函数；凸函数在紧凸集上的最大值必在极点（顶点）取得。再对 $b$ 同理。$\blacksquare$

**能干什么**：把"无穷多对点"缩成 $m(m-1)/2$ 次距离计算。
$m\le32$ ⟹ 最多 496 次。**且结果是精确值，不是数值近似的。**

> 旋转卡壳可降到 $O(m)$，但本题**不需要**；论文里提一句当加分点即可。

### 步骤 5 — 覆盖判定

| 项 | 内容 |
| --- | --- |
| **输入** | 顶点集 + 直径端点 $A,B$ |
| **定理** | **圆盘是闭凸集 ⟹ 只需检查极点**（多边形时即顶点，推论 3.1） |
| **公式** | $p$ 在圆内 $\iff(A-p)\cdot(B-p)\le0$（泰勒斯） |
| **输出** | 布尔值；若否，指出哪个顶点跑出去了 |

**为什么只查顶点就够？** 圆盘是**闭凸集**，由极点原理 $\mathcal{P}=\operatorname{conv}(\operatorname{ext}\mathcal{P})$，故
$$\operatorname{ext}\mathcal{P}\subseteq\text{圆盘}\iff\mathcal{P}\subseteq\text{圆盘}$$
两个方向都成立（$\Leftarrow$ 用凸组合封闭性，$\Rightarrow$ 因 $\operatorname{ext}\mathcal{P}\subseteq\mathcal{P}$）。$\blacksquare$

**推论 3.1（多边形情形）** 凸多边形的极点恰为其顶点，故
$$\text{全部顶点}\in\text{圆盘}\iff\text{凸包}\subseteq\text{圆盘}\iff\mathcal{P}\subseteq\text{圆盘}$$

> ⚠ **前提**：$\Omega$ 是圆盘之交，边界含圆弧，$\mathcal{P}$ 一般**不是**多边形。
> 须先作边界形态约定（`问题1-引理与证明.md` §0.5）：**主**——验证 $\Omega$ 不活化（本题全区域安全余量 $285.9$ m，成立）；
> **兜底**——$\Omega$ 作 $K$ 边内接正多边形近似（$K=360$ 时误差 $\approx0.068$ m）。

**能干什么**：

1. **把"圆能否覆盖多边形"这个连续包含判定，降成有限次点积比较**
2. **泰勒斯形式免开根号、免算圆心**，纯符号运算
3. 答案是**确定的**（不是概率、不是近似），因为输入用的是误差区间而非分布

### 步骤 6 — 最小包围圆（通向问题 3 的桥）

| 项 | 内容 |
| --- | --- |
| **输入** | 顶点集 |
| **定理** | 最小包围圆必由 **2 个或 3 个**点确定 |
| **做法** | 暴力枚举所有点对（直径圆）与三点组（外接圆），取能覆盖全集的最小者 |
| **输出** | $r_{\text{MEC}}$ |

**为什么需要它？** 因为**题目问的圆，不是操作上真正要用的圆**：

| | 问题 |
| --- | --- |
| 题目问 | 以**直径**为直径的圆，能否覆盖定位区域？ |
| 操作上要答 | 能不能找到一个位置，站上去就能清除区域内**任意**一点？ |

后者等价于：**$r_{\text{MEC}}\le r_{\text{clear}}=20$ m？**

**由 Jung 定理**：$\dfrac{\mathcal{D}}{2}\le r_{\text{MEC}}\le\dfrac{\mathcal{D}}{\sqrt3}$

**关键等价命题**（已数值验证）：
$$\mathcal{P}\subseteq\mathcal{C}\!\left(M,\tfrac{\mathcal{D}}{2}\right)\iff r_{\text{MEC}}=\frac{\mathcal{D}}{2}$$

即：**"直径圆能否覆盖"这一问，等价于问"这个区域的最小包围圆是不是恰好就是直径圆"**——本质上是在问区域**够不够钝**。

**能干什么**：

1. 给出"能否找到一点覆盖整个区域并在 20 m 内清除"的**确定回答**
2. 因 $r_{\text{MEC}}\ge\mathcal{D}/2$ **恒成立**，得到**无条件结论**：
   本题 $\mathcal{D}/2=87.9$ m $\gg20$ m ⟹ **远场交会定位不可能直接清除，逼近是强制的**

### 步骤 7 — 验证与灵敏度

| 验证项 | 做法 | 能干什么 |
| --- | --- | --- |
| **实例回归** | 用 9/10 演练的真实两条示向度，检验 $\mathcal{D}=175.8$ m | 证明算法能跑、数值对得上 |
| **坐标系自洽** | 交点回代验算方位角 = 输入示向度 | 排除"静默错误"（坐标系搞反不报错） |
| **灵敏度：$r_{\text{eff}}$** | 取 $1000/1250/1500$ | 说明未知参数的影响幅度 |
| **灵敏度：$\varepsilon$** | 取 $0.5°/1.0°$ | 说明测向精度的影响 |
| **蒙特卡洛** | 按 $[-1°,1°]$ 抽样真误差，看 $\mathcal{D}$ 的分布 | 补上"区间法给不出概率"这一短板 |

> **蒙特卡洛这一条值得写**：题设说"同一地点误差固定、只有跨地点才呈现统计规律"，
> 所以严格来说应该**对每个检测点先固定一个误差值**（层内固定），再跨检测点抽样（层间随机）。
> 这比直接对每个示向度独立抽样更贴合题意，是加分点。

## §4 公式 / 定理速查表

> 你要的版本：**只列出来，说明能干什么**。

| # | 公式 / 定理 | 表达式 | 能干什么 |
| --- | --- | --- | --- |
| 1 | **楔形 → 半平面** | $u_i\times(p-S_i)\ge0$ 且 $v_i\times(p-S_i)\le0$ | 把非线性角度约束**线性化**，后续全变标准计算几何 |
| 2 | **叉积恒等式** | $a\times b=|a||b|\sin(\angle b-\angle a)$ | 解释 1 为什么成立；也是**防写反**的检查依据 |
| 3 | **凸性引理** | 凸集 ∩ 凸集 = 凸集 | 保证区域是**凸集**（边界约定下为凸多边形）⟹ 步骤 4、5 能用枚举 |
| 4 | **直径在极点**（推论 2.1） | $\operatorname{diam}(\mathcal{P})=\max_{\text{极点对}}\lVert p_j-p_k\rVert$ | **无穷点对 → 有限点对**，且结果精确 |
| 5 | **覆盖查极点**（推论 3.1） | $\mathcal{P}\subseteq\mathcal{C}\iff\operatorname{ext}\mathcal{P}\subseteq\mathcal{C}$ | **连续包含判定 → 有限次比较** |
| 6 | **泰勒斯定理** | $p$ 在圆内 $\iff(A-p)\cdot(B-p)\le0$ | **免开根号**的圆内判定，纯符号运算 |
| 7 | **最小包围圆** | 必由 2 或 3 个点确定 | 求清除可行性，**题目没问但操作上必须有** |
| 8 | **Jung 定理** | $\mathcal{D}/2\le r_{\text{MEC}}\le\mathcal{D}/\sqrt3$ | 给 $r_{\text{MEC}}$ 的**区间**，不精确算也能下结论 |
| 9 | **等价命题** | 覆盖 $\iff r_{\text{MEC}}=\mathcal{D}/2$ | 打通"覆盖判定"与"最小包围圆"，揭示本质是**区域够不够钝** |

## §5 复杂度

| 步骤 | 复杂度 | $n=16$ 时的量级 |
| --- | --- | --- |
| 1 半平面构造 | $O(n)$ | 32 次三角运算 |
| 2 求交 + 筛 | $O(n^3)$ | ~8000 次乘法 |
| 3 极角排序 | $O(m\log m)$ | 32·5 ≈ 160 |
| 4 直径 | $O(m^2)$ | ≤496 |
| 5 覆盖判定 | $O(m)$ | 32 |
| 6 最小包围圆 | $O(m^3)$ | ≤5000 |
| **合计** | $O(n^3)$ | **微秒级** |

> **结论：整条流水线在现代 CPU 上是瞬时的。**
> 因此问题 3/4 的策略瓶颈**完全不在几何计算，而在虚拟时间**（移动、检测、频道切换）。
> 这一点直接决定问题 3 的优化方向：**省时间要靠少走冤枉路，不是靠算得快。**

## §7 与问题 2/3/4 的接口

| 下游 | 复用本流程的哪部分 |
| --- | --- |
| **问题 2** | 步骤 1–4 作为**评价函数**：给定候选第二个检测点 $S_2$，算出 $\mathcal{D}$，$\mathcal{D}$ 越小则该点越好。目标函数自然形式是 $1/\sin\gamma$（交会角放大因子） |
