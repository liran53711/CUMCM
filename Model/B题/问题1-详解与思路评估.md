## §1 拆开讲「问题 1：怎么建模 n 个楔形的交」

### 1.1 先把物理场景说成人话

一个干扰源在某个位置。一台测向机站在 $S$，测得方位角 $\theta$。

如果测向机是完美的，那源就在从 $S$ 出发、沿 $\theta$ 方向的那条**射线**上。

但测向机有 $\pm1°$ 误差。所以源不在"一条线"上，而在**一片很窄的区域**里：

```
                    ↑ y
                    │
                    │        ╱  ← 上边界 v ：方位 θ+1°
                    │      ╱
                    │    ╱
                    │  ╱    ← 楔形内部，张角只有 2°
                    │╱
       ─────────────●────────────────────────→ x
                    │╲
                    │  ╲
                    │    ╲  ← 下边界 u ：方位 θ−1°
                    │      ╲
                    S
                 检测点
```

这片区域叫**楔形**：以 $S$ 为顶点、张角 $2°$、朝 $\theta$ 方向**无限延伸**的一个角域。

> ⚠ **「无限延伸」这四个字是后面的关键**，先记住。

现在有 $n$ 台测向机，各测一次。源必须同时满足所有 $n$ 个"我能看到它"的约束，所以：

$$\text{源的位置} \in \text{所有 } n \text{ 个楔形的交集}$$

```
   检测点 A ●                              ● 检测点 B
             ╲                            ╱
              ╲   各 2° 宽的射线束      ╱
               ╲                        ╱
                ╲  __________________  ╱
                 ╲ ╲                ╱ ╱
                  ╲ ╲  定位区域    ╱ ╱   ← 交集是块细长条
                   ╲ ╲（细长四边形）╱ ╱
                    ╲ ╲____________╱ ╱
                     ╲                ╱
```

**到这里，问题 1 的建模对象就清楚了：求 $n$ 个无限楔形的交集。**

---

### 1.2 第一步：不要想着「画出来」，先学会「判在不在里面」

这是整个问题的转折点。

你的直觉可能是："我得先把这个多边形算出来，才能研究它。" 但**先算形状是最难的路**。

**换个方向：先回答一个更简单的问题——给定一个点 $p$，它在不在第 $i$ 个楔形里？**

几何上显然的判法：算出 $S_i$ 指向 $p$ 的方位角，看它在不在 $[\theta_i-1°,\ \theta_i+1°]$ 里。

```
        S_i 指向 p 的方位角 = φ
        ┌───────────────────────────────┐
        │  θ_i−1°  ≤  φ  ≤  θ_i+1°  ?  │
        └───────────────────────────────┘
```

**这个判法是对的，而且最好懂。** 直接实现也没问题。

但它有两个工程上的麻烦：

1. 要算 `atan2`，比乘法慢（本题无所谓，但不够漂亮）
2. **`0°` 附近要处理绕圈**——方位可能是 $359°$ 或 $1°$，区间跨过 $0°$ 时要特判，容易写错

所以文献和代码里常用**叉积**写法，绕开这两个麻烦：

$$u_i\times(p-S_i)\ \ge\ 0 \qquad\text{且}\qquad v_i\times(p-S_i)\ \le\ 0$$

**怎么理解这两个式子？** 记住一条恒等式：

$$a\times b \;=\; |a|\,|b|\,\sin(\angle b-\angle a)$$

所以 $a\times b>0$ 的意思是：**从 $a$ 逆时针转到 $b$，转过的角在 $(0°,180°)$ 内。**

代进去看：

| 式子 | 含义 |
| --- | --- |
| $u_i\times(p-S_i)\ge0$ | 从"下边界"逆时针转到"$S_i$ 指向 $p$ 的方向"，角不超过 $180°$。也就是**方位 $\ge\theta_i-1°$** |
| $v_i\times(p-S_i)\le0$ | 同理，**方位 $\le\theta_i+1°$** |
| 两式同时成立 | **方位落在 $[\theta_i-1°,\ \theta_i+1°]$ 内** ✅ |

**和"算角度比大小"完全等价，但只用乘法和减法，且天然不怕绕圈。**

---

### 1.3 ⚠ 一个真实的坑：叉积次序不能颠倒

我第一版文档里把这两个式子写成 $(p-S_i)\times u_i$，**符号是反的**。这个错误很值得讲，因为它**不会报错**。

**数值验证**（检测点在原点，$\theta=0°$，$\varepsilon=1°$，肉眼就能判断期望值）：

| 测试点 | 应否在楔内 | $(p-S)\times u$ 式 | $u\times(p-S)$ 式 |
| --- | --- | --- | --- |
| $(10,\ 0)$ 正东 10 m | 在 | ✗ 判成"不在" | ✅ |
| $(10,\ 0.15)$ 偏北 0.86° | 在 | ✗ | ✅ |
| $(10,\ 0.20)$ 偏北 1.15° | 不在 | ✅（蒙对） | ✅ |
| $(10,\ -0.15)$ 偏南 0.86° | 在 | ✗ | ✅ |
| $(0,\ 10)$ 正北 | 不在 | ✅（蒙对） | ✅ |
| $(-10,\ 0)$ 正西 | 不在 | ✗ 判成"在" | ✅ |

**扫描整个圆周，看两个公式各自接受哪些方位角：**

| 公式 | 接受的方位角区间 |
| --- | --- |
| $(p-S_i)\times u_i\ge0$ 且 $(p-S_i)\times v_i\le0$（**错**） | $[179.0°,\ 181.0°]$ |
| $u_i\times(p-S_i)\ge0$ 且 $v_i\times(p-S_i)\le0$（**对**） | $[359.0°,\ 1.0°]$ |

> **错的那个把楔形转到了 $180°$ 的反方向。**
>
> **这才是最可怕的地方**：它仍然是一个 $2°$ 宽的细长条，**看起来完全合理**，
> 程序不报错、结果不崩溃，但源会被定位到检测点的**另一侧**。
>
> 换句话说：**这是个"静默错误"，只能靠肉眼核对或数值测试发现。**

**已修正**：`问题1-定位区域直径算法.md` §4.1 与 `问题1-直观方法推导.md` 均已改回正确次序。

### 1.4 第二步：从「判定」到「多边形」

有了判定函数，求多边形就变得很直接了。

**关键观察**：定位区域的边界，一定落在某几条楔形边界射线上。所以——

> **区域的每一个顶点，必定是两条射线的交点。**

于是算法只有两步：

```
第 1 步：生成候选点
    所有 2n 条射线（n 个检测点 × 每个 2 条边界）两两求交
    → 得到约 2n² 个候选点

第 2 步：筛
    对每个候选点 p，用 1.2 的判定函数查一遍：
        全过 → p 是真正的顶点，留下
        有一个不过 → 丢掉
```

**就这么多。** 不需要什么高深算法。

**复杂度**：$C(2n,2)\approx 2n^2$ 个候选，每个查 $n$ 次 → $O(n^3)$。
$n\le16$ 时不到 8000 次乘法，**现代 CPU 上是微秒级，完全不用优化**。

> **这个"穷举+筛"就是你的思路 1 的答案。**
> 它比教科书上的 Sutherland–Hodgman 裁剪算法更笨，但**更好懂、更好写、更好验证**——
> 在竞赛场景下这是优点不是缺点。

### 1.5 共同特征里，哪一条是「承重墙」

你问"这种多边形有什么共同特征，以及特征是否有用"。答案是：

| # | 特征 | 承重吗 |
| --- | --- | --- |
| **1** | **一定是凸多边形** | 🔴 **承重**——问题 2、3 全靠它 |
| 2 | 顶点数 $\le 2n$ | 🟡 半承重——决定复杂度上界 |
| 3 | 顶点来自不同检测点的两条射线 | 🟡 半承重——把"无穷多点"缩成"有限候选" |
| 4 | 通常是个细长条 | ⚪ 不承重——只是好看的解释 |

**为什么特征 1 是承重墙？** 因为：

> **凸性一确立，问题 2 和问题 3 立刻从「在无穷多个点上做连续优化」塌缩成「在有限个顶点上做枚举」。**

后者是**三十行代码就能写完、且结果精确**的问题；前者是**需要数值优化、还有收敛风险**的问题。

**这是问题 1 全部价值所在。** 论文里应当把凸性单独拎出来立为引理。

**特征 1 从哪来？** 两个凸集（楔形是凸的、圆盘是凸的）的交仍是凸集。一行就能证。

## §2 拆开讲「问题 2：找最远两点」

### 2.1 为什么不能「随便取两点」

"区域内最远两点"，字面意思是对**所有**点对求最大：

$$\mathcal{D}=\max_{a,b\ \in\ \mathcal{P}}\ \lVert a-b\rVert_2$$

但区域里有**无穷多个点**，点对更是无穷多。直接做是不可能的。

所以问题变成：

> **能不能把「无穷多个点」缩小到一个有限集合，而不改变最大值？**

### 2.2 凸性给出了答案

**能。取顶点就够了。**

举个人眼能验的例子——一个长方形，四角 $A(0,0)$、$B(4,0)$、$C(4,2)$、$D(0,2)$：

```
      D ●───────────────────● C
        │                   │          最远两点 = 对角线
        │   最远的对角线    │          A–C 或 B–D
        │   ≈ 4.47 m        │          两条都是 4.47 m
        │                   │
      A ●───────────────────● B
                                     两条边的中点距离只有 2 m
```

- 对角线 $A$–$C$：$\sqrt{4^2+2^2}=4.47$
- 两条对边中点：$2$
- 任取一个角和一个边中点：比如 $A$ 到 $BC$ 中点 $(4,1)$，距离 $\sqrt{16+1}=4.12<4.47$

**发现了吗：无论怎么试，都赢不过「角顶角」。**

**为什么？** 用一句话说：

> **顶点是凸多边形最"鼓"出去的地方。边上、内部的点都夹在角中间，撑不远。**

**严格证明**（论文里要写）：固定 $b$，函数 $a\mapsto\lVert a-b\rVert$ 是**凸函数**。
凸函数在紧凸集上的最大值必在**极点**（对多边形就是顶点）取得。
再对 $b$ 用同样的论证，两次合起来 ⟹ 直径必在顶点对之间取到。$\blacksquare$

### 2.3 反过来看：如果多边形是凹的呢？

**这个方法论很重要**——理解"什么时候会坏"，才知道"为什么现在没坏"。

凹多边形（比如一个 L 形）里，最远的两点**可能落在凹口的两个尖角上，而那里不是凸包顶点**。只查顶点就会漏。

```
     ●─────────●
     │         │            在 L 形里，最远两点
     │         │            可能出现在这两个位置
     │   ┌─────●            而它们都不是"角"
     │   │                  ↑ 凹口处
     ●───┘
```

**本题不会出现这种情况**，因为 $n$ 个楔形的交必为凸集。

> **所以"凸性"不是一句漂亮话，它是在说：本题恰好落在"暴力枚举正确"的那一侧。**

### 2.4 实现：两层循环，完事

```python
for j in range(m):
    for k in range(j+1, m):
        更新最大距离
```

$m\le2n\le32$ ⟹ 最多 496 次距离计算。**一眨眼的事。**

**旋转卡壳（rotating calipers）** 能把复杂度降到 $O(m)$，但那是给 $m$ 上千的凸包用的。本题**不需要**。
论文里可以写一句"可用旋转卡壳优化至 $O(m)$"——表明你知道更优算法，但基于 $m$ 的量级选择不实现。这是加分项。

## §3 拆开讲「问题 3：判断圆盖不盖得住」

### 3.1 先把题目问什么说清楚

问题原话：

> **以定位区域直径为直径的圆，能否覆盖此定位区域？**

设最远两点为 $A,B$，则

$$\mathcal{D}=\lVert A-B\rVert,\qquad M=\frac{A+B}{2},\qquad R=\frac{\mathcal{D}}{2}$$

要判的就是：**区域内有没有哪一点，到 $M$ 的距离大于 $R$。**

**你原话问的就是这个**——"有没有多边形上的点到这个最长距离的中点的距离长于半径"。**一字不差，问得非常准。**

### 3.2 一个能省掉一半工作的观察

> 🔑 **$A$ 和 $B$ 本来就在圆上。**

因为圆的直径**就是**线段 $AB$，而 $A,B$ 是它的两端。它们到 $M$ 的距离恰好是 $R$，不多不少。

所以问题等价于：

$$\boxed{\text{除了 } A,B \text{ 之外，还有没有别的顶点跑到圆外去了？}}$$

### 3.3 为什么只查顶点就够？——这里用的凸性和问题 2 不同

**注意区别**，这是本题最容易被问倒的地方：

| | 凸性在论证什么 |
| --- | --- |
| **问题 2** | 「**最大值**一定在顶点处取得」 |
| **问题 3** | 「**只需检查顶点**就足够」 |

**问题 3 的理由**：圆（圆盘）是凸集；凸多边形恰好等于它顶点的凸包。于是

$$\text{所有顶点都在圆盘内} \iff \text{顶点的凸包}\subseteq\text{圆盘} \iff \mathcal{P}\subseteq\text{圆盘}$$

**正反两个方向都成立**：

- 顶点全在圆盘内 ⟹ 区域内每点都在（因为圆盘凸）✅
- 有顶点在圆盘外 ⟹ 盖不住（因为那个顶点**本身就是**区域里的点）✅

### 3.4 一个具体例子：什么时候盖得住、什么时候盖不住

**例 A：长方形** $A(0,0),B(4,0),C(4,2),D(0,2)$，直径 $AC$，圆心 $M=(2,1)$，$R=2.236$

| 顶点 | 到 $M$ 的距离 | 判定 |
| --- | --- | --- |
| $A(0,0)$ | $2.236$ | 在圆上 |
| $C(4,2)$ | $2.236$ | 在圆上 |
| $B(4,0)$ | $2.236$ | 在圆上 |
| $D(0,2)$ | $2.236$ | 在圆上 |

**全部恰好落在圆上**——这是长方形（圆内接四边形）的性质。**盖得住。**

**例 B：锐角三角形** $A(0,0),B(4,0),C(2,3)$，直径 $AB=4$，圆心 $M=(2,0)$，$R=2$

<table>
<tr><td><pre>
            C ●
             ╱ ╲           直径 = AB = 4
            ╱   ╲          圆 = 以 M(2,0) 为心、R=2
           ╱     ╲
          ╱   ×   ╲   ← C 到 M 距离 = 3 > 2
         ╱   ↑     ╲     跑出圆外了！
        ╱    M      ╲
      A ●───────────● B
</pre></td></tr>
</table>

$C(2,3)$ 到 $M=(2,0)$ 的距离是 $3>2=R$。**盖不住！**

**这两个例子说明什么？**

> **直径圆能否覆盖，取决于区域「够不够钝」。**
> 长方形四角都是直角 → 恰好覆盖；
> 锐角三角形有一个尖角 → 尖角戳出圆外。

**用泰勒斯定理可以直接判定**：顶点 $p$ 在圆内 $\iff\angle ApB\ge90°$。
例 B 中 $\angle ACB$ 是锐角（$\vec{CA}\cdot\vec{CB}=5>0$）⟹ $C$ 在圆外。

### 3.5 实现：泰勒斯等价形式

不想开根号、不想算圆心，可以只用**点积符号**：

$$\mathbf{p} \text{ 在圆内} \iff \angle A\mathbf{p}B\ \ge\ 90° \iff (A-\mathbf{p})\cdot(B-\mathbf{p})\ \le\ 0$$

> **泰勒斯定理**：$A,B$ 为直径两端时，圆周上任一点 $P$ 满足 $\angle APB=90°$；
> 圆内为钝角（点积为负），圆外为锐角（点积为正）。

**纯符号运算，比"算距离再比大小"更稳健。**

### 4.2 好在哪（具体说）

1. **分解方式正确**。你把问题拆成「区域结构 → 直径 → 覆盖判定」三步，这**恰好就是**计算流程的三步。这种拆法不是"看起来合理"，是**可以逐段实现和验证**的。

2. **第 1 问里加了一句"特征是否有用"**。这是**建模思维 vs 描述思维**的分水岭。描述思维会满足于"它是凸的、它有 2n 个顶点"；建模思维会追问"所以呢？这能让我少算什么？"——你问了。

3. **第 2 问的提法直接挂钩数学定义**。你没问"怎么用算法找最远点"，而是问"有什么方法找最远两点"。前者容易一头扎进具体算法（比如一上来就想旋转卡壳），后者的问法保留了"能不能用更简单的办法"的空间。**结果就是：本题真的只需要暴力枚举。**

4. **第 3 问的转化是正确且高效的**。把"圆覆盖多边形"转成"点到圆心距离 vs 半径"，这一步把**几何包含问题**化成了**标量比较问题**。这是很标准的建模降维手法，你用对了。

### 4.3 缺口在哪（三条，按严重程度排序）

#### 🔴 缺口一：**有界性**（最致命）

**你的三个问题，全部默认定位区域是一个有界多边形。**

但楔形是**无限延伸**的角域。$n=1$ 时区域无限大；两射线近乎平行时区域拉得极长。

**后果**：直径可能是 $\infty$，此时问题 2 和问题 3 **根本没有答案**，不是在"求一个很大的数"，而是**问题本身不成立**。

**这是唯一一个"不想清楚就交不了差"的缺口。** 因为：

- 论文里必须**显式声明**外部边界 $\Omega$ 是什么、为什么这么选
- 它不是"选做题"，是"必答题"——不加边界，模型在数学上不完备

**怎么补**：见 §5.1。

#### 🟡 缺口二：用"特征清单"而不是"承重特征"

你问"有什么共同特征"。这个问题会得到一张清单（凸、$\le2n$ 个顶点、细长……）。

但**清单本身不产生算法**。真正要问的是：

> **这些特征里，哪一条让"暴力枚举"从错误变成正确？**

答案是"凸性"这一条，其余都只是修饰。**论文里如果只给清单，评委会觉得"观察到了但没吃透"；如果点出"凸性是承重墙"，就是"理解了结构"。**

#### 🟡 缺口三：没有触及"为什么能只查顶点"

你问"有什么方法找最远两点"，但没问"**为什么暴力枚举顶点是对的**"。

这个"为什么"就是凸性引理的证明，**是问题 1 的数学核心**。不写它，算法就只是"我试了试发现可以"；写了它，算法才是"由定理保证正确"。

**竞赛论文里这两者的分差是实打实的。**

#### ⚪ 缺口四：退化情形

- $n=1$（只有一台测向机）
- 两条射线近乎平行
- $n$ 个楔形的交为**空**（数据自相矛盾）

这些不影响主流程，但**灵敏度分析/模型检验章节需要**。

### 4.4 一句话总结你的思路

> **方向全对，分解全对，转化全对。**
> **唯一的结构性遗漏是"有界性"——而且它恰好是不能靠聪明才智绕过去、只能靠显式假设解决的那一类问题。**
> **另一个层面的建议是：把"特征"升级成"承重特征"，把"方法"升级成"定理保证的方法"。**

## §5 我建议的更好版本

### 5.1 补上外部边界（这是最优先的一步）

楔形无限延伸，必须人为加边界。题目里有两个"天然的"边界可用：

| 方案 | 依据 | 评价 |
| --- | --- | --- |
| $\Omega=$ 目标区域圆（$R=1800$ m） | 题干：源在目标区域内 | 最保守，一定成立 |
| $\Omega=$ 有效接收半径圆盘（$R=r_{\text{eff}}\le1500$ m） | 附录 2(2)：能测到说明距离不超过 $r_{\text{eff}}$ | **信息更强**，收得更紧 |
| **两者取交** | 上述两条都成立 | **最紧，推荐** |

**为什么推荐"取交"**：因为源必须同时满足"在目标区域内"和"被检测点测到"两个条件。取交是把两条已知信息都用上，没有任何额外假设。

**但有个坑**：$r_{\text{eff}}$ 的具体值**接口不返回**，只知道在 $[1000,1500]$ 内。

**处理办法**：用 $r_{\text{eff}}=1500$（最大的那个）构造圆盘。
理由：$r_{\text{eff}}$ 越大，圆盘越大、约束越松，所以用最大值得到的区域**一定包含真实区域**——这是**保守的、安全的**。
然后在灵敏度分析里讨论 $r_{\text{eff}}$ 取 $1000$ / $1250$ / $1500$ 时直径怎么变。

> **这个"取值不定就取保守侧"的思路，可以直接复用到问题 2。** 是个通用的建模手法。

**取交之后的定位区域**：

$$\mathcal{P}=\underbrace{\text{目标区域圆}\ \cap\ \text{半径}1500\text{ 的圆盘}}_{\textstyle \Omega}\ \cap\ \bigcap_{i=1}^{n}\bigl(H_i^- \cap H_i^+\bigr)$$

三个都是凸集，所以 $\mathcal{P}$ 仍是**凸集**。**前面的全部结论一条都不作废。**

> ⚠ **但有一处要说清**：$\Omega$ 是两个**圆盘**之交，边界含**圆弧**，故 $\mathcal{P}$ 一般**不是多边形**。
> 「$\mathcal{P}$ 是凸多边形」是后面引理 2/3 的多边形版本（推论 2.1 / 3.1）的**前提**，不能默认成立。
> 处理方式见 `问题1-引理与证明.md` §0.5「边界形态约定」：
> **主路线**——验证 $\Omega$ 不活化（本题**全区域安全余量** $R-\lVert P_0-c\rVert-\mathcal{D}=285.9$ m，是区域半径 $87.9$ m 的 $3.25$ 倍，故 $\partial\Omega\cap\partial\mathcal{P}=\varnothing$），
> 此时 $\mathcal{P}$ 由楔形完全决定，**天然是多边形，零近似误差**；
> **兜底路线**——若某组数据下 $\Omega$ 活化，则把 $\Omega$ 换成 $K$ 边内接正多边形（弓高误差 $\le R(1-\cos\frac{\pi}{K})$，$R=1800$、$K=360$ 时 $\approx0.068$ m），并在模型假设中声明 $K$。

### 5.2 把"特征清单"换成"一条承重特征 + 两条辅助"

论文里建议这样组织：

> **引理 1（凸性）** 定位区域 $\mathcal{P}$ 是凸集。
> *证明*：每个楔形是凸集；圆盘是凸集；凸集的交仍是凸集。$\blacksquare$
>
> **引理 2（直径在极点处取得）** $\operatorname{diam}(\mathcal{P})=\max_{a,b\in\operatorname{ext}\mathcal{P}}\lVert a-b\rVert$。
> **推论 2.1（问题 2，多边形情形）** 直径必在**顶点**取得。
> **引理 3（覆盖只需检查极点）** 对闭凸集 $\mathcal{C}$，$\mathcal{P}\subseteq\mathcal{C}\iff\operatorname{ext}\mathcal{P}\subseteq\mathcal{C}$。
> **推论 3.1（问题 3，多边形情形）** 覆盖判定只需检查**顶点**。
> **性质（规模）** 顶点数 $m\le2n$，故枚举代价 $O(n^2)$ 可忽略。
> **性质（形态）** 张角仅 $2°$，故区域狭长，直径由两端尖角决定。

**从"清单"变成"一条引理带两个推论"——结构上立刻高级一档，而且信息量没变。**

### 5.3 一个更本质的重构：问题 1 问的那个圆，不是真正该用的圆

这是我最想推荐的一条，**它能让你从"做题"变成"建模"**。

**题目问的**：以**直径**为直径的圆，能否覆盖区域。

**但清除操作实际关心的是**：能不能找到一个位置，站上去就能清除区域内任意一点？

$$\text{能做到} \iff \text{存在一点，到区域内任意点的距离}\le r_{\text{clear}}=20\text{ m}$$

$$\iff \text{区域的\textbf{最小包围圆}半径}\le20\text{ m}$$

**注意：最小包围圆 ≠ 直径圆，而且方向可能和直觉相反。**

由 Jung 定理：

$$\frac{\mathcal{D}}{2}\ \le\ r_{\text{MEC}}\ \le\ \frac{\mathcal{D}}{\sqrt3}$$

| | 含义 | 与 $\mathcal{D}/2$ 的关系 |
| --- | --- | --- |
| $\mathcal{D}/2$ | 题目问的**直径圆**的半径 | 是 $r_{\text{MEC}}$ 的**下界** |
| $r_{\text{MEC}}$ | 操作上真正要用的**最小包围圆**半径 | 恒 $\ge\mathcal{D}/2$，最多大 $2/\sqrt3-1\approx15.5\%$ |

> ⚠ **方向容易记反**：最小包围圆是"最省的那个圆"，直觉上会以为它比直径圆**小**；
> 实际上它恒 $\ge\mathcal{D}/2$。原因见下面的等价命题。

### 关键等价命题

$$\boxed{\ \mathcal{P}\subseteq\mathcal{C}\!\left(M,\tfrac{\mathcal{D}}{2}\right)\iff r_{\text{MEC}}(\mathcal{P})=\frac{\mathcal{D}}{2}\ }$$

*证明*：
**(⟸)** 设 $r_{\text{MEC}}=\mathcal{D}/2$，则存在半径 $\mathcal{D}/2$ 的圆盘 $\mathcal{C}'$ 包含 $\mathcal{P}$。因 $A,B\in\mathcal{P}$ 且 $|AB|=\mathcal{D}$，故 $A,B$ 都在 $\mathcal{C}'$ 内。而半径 $\mathcal{D}/2$ 的圆盘自身直径恰为 $\mathcal{D}$，故 $A,B$ 必是 $\mathcal{C}'$ 的一对对径点，从而 $\mathcal{C}'=\mathcal{C}(M,\mathcal{D}/2)$，即 $\mathcal{P}\subseteq\mathcal{C}(M,\mathcal{D}/2)$。
**(⟹)** 若 $\mathcal{P}\subseteq\mathcal{C}(M,\mathcal{D}/2)$，则 $r_{\text{MEC}}\le\mathcal{D}/2$；又由 Jung 下界 $r_{\text{MEC}}\ge\mathcal{D}/2$，故相等。 $\blacksquare$

> **翻译成人话**：题目问的"直径圆能否覆盖"，**等价于**问"这个区域的最小包围圆，是不是恰好就是直径圆"。
>
> 也就是说，**问题 1 的覆盖判定本质上在问「这个区域够不够钝」**——
> 区域够钝（长方形、钝角三角形），直径圆就是它的最小包围圆；
> 区域有尖角（锐角三角形、等边三角形），最小包围圆就**必须**比直径圆大。

**数值验证**（4 个形状，已跑通）：

| 形状 | $\mathcal{D}$ | $\mathcal{D}/2$ | $r_{\text{MEC}}$ | $\mathcal{D}/\sqrt3$ | 直径圆覆盖 |
| --- | --- | --- | --- | --- | --- |
| 长方形 | 4.4721 | 2.2361 | 2.2361 | 2.5820 | ✅ 是 |
| 钝角三角形 | 4.0000 | 2.0000 | 2.0000 | 2.3094 | ✅ 是 |
| 锐角三角形 | 4.0000 | 2.0000 | 2.1667 | 2.3094 | ❌ 否 |
| 等边三角形 | 4.0000 | 2.0000 | **2.3094** | 2.3094 | ❌ 否 |

> 等边三角形恰好取到 Jung 上界 $r=\mathcal{D}/\sqrt3$，是"最尖"的极端情形。
> 四个形状中"直径圆覆盖 $\iff r_{\text{MEC}}=\mathcal{D}/2$"**全部成立**，命题送检通过。

**本题实测数据落在相等的情形**（$r_{\text{MEC}}=87.9$ m $=\mathcal{D}/2$），即定位区域够钝，直径圆确实是它的最小包围圆。

> ⚠ **但这是这一组数据的性质，不是定理。** 换一组检测点就可能不成立。

### 操作结论（比原来的更强）

因为 $r_{\text{MEC}}\ge\mathcal{D}/2$ **恒成立**，而本题实测 $\mathcal{D}/2=87.9$ m $\gg r_{\text{clear}}=20$ m：

$$\text{无论定位区域的形状如何，都不可能找到一个点同时覆盖整个区域并落在清除半径内}$$

**这个论证只用了下界，不依赖"直径圆是否覆盖"的判定结果——所以它是无条件成立的。**

**论文里的建议写法**：

1. 正面回答问题 1：给出直径 $\mathcal{D}$，并判定直径圆是否覆盖 ✅
2. **追加一节**：指出操作上真正需要的是最小包围圆，给出 $r_{\text{MEC}}$，并说明两者何时一致
3. 由 $r_{\text{MEC}}\gg20$ m 得出**强结论**：
   **远场交会定位不足以直接清除，逼近是强制的、不是可选的优化项。**

**第 3 条是问题 1 到问题 3 的桥梁**，也是全文最重要的物理结论之一。而且它回答的是评委会想的问题："你算了这个直径，然后呢？"

### 5.4 顺带一提：还有个不依赖示向度的定位方法

见 `接口信息可用性分析.md` §4 的**边界圆法**。

`direction` ↔ `no_signal` 的跳变边界是一个**以源为圆心、半径恰为 $r_{\text{eff}}$ 的圆**。沿直线找两个跳变点即得一条弦，弦的垂直平分线过圆心；两条这样的线求交，即得**源的精确位置**。

**与交会定位互补**：交会法给"角度约束下的可行域"，边界圆法给"距离约束下的精确点"。**两法结果若不一致，说明模型或实现有错**——这是一条免费的交叉验证。
