# Model/ — 建模手工作区

主编辑：集成电路同学（建模手）。

## 目录用途

存放建模思路、变量定义、公式推导、目标函数、约束条件、算法流程、模型检验与敏感性分析。
给 `Coding/` 提供可实现的算法流程；给 `Writing/` 提供公式与假设依据。

## 建模手职责

1. 读题后 30 分钟内给出：目标变量、决策变量、约束、数据需求、评价指标。
2. 每个模型按 `CUMCM/AGENTS.md` 的模型模板输出（适用问题 → 符号定义 → 核心假设 → 数学表达 → 求解步骤）。
3. 所有公式用 LaTeX，不用未定义符号，参数说明现实含义。
4. 保证模型能算：给 `Coding/` 的算法流程必须可落地，含参数估计与验证方法。
5. 负责敏感性/稳健性分析设计。
